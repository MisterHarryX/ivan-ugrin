# Иван Угрин — концепт сайта психолога

Концепт сайта для Ивана Угрина — интегрального психолога и экзистенциального философа. Сайт построен на нашем шаблоне `E:\Psixolog`: запись на консультацию, кабинет с заявками, правка текстов прямо на странице. Пожелания Ивана собраны в памяти проекта, а коротко они перечислены ниже.

## Запуск

```powershell
Set-Location E:\PsiloogIvan
npm run dev -- --host 127.0.0.1 --port 5177 --strictPort
```

- Сайт: http://127.0.0.1:5177/
- Кабинет: http://127.0.0.1:5177/admin. Пароль лежит в `.env.local` (`ADMIN_PASSWORD`), в git файл не попадает.

## Сайт в интернете

- Адрес: https://ivan-ugrin.vercel.app (Vercel, команда `writelite`, проект `ivan-ugrin`).
- Кабинет: https://ivan-ugrin.vercel.app/admin, пароль задан в переменной `ADMIN_PASSWORD` проекта на Vercel (и локально в `.env.local`).
- Редактор на сайте: войдите в кабинет и откройте https://ivan-ugrin.vercel.app/?edit. Правка любого текста, фото, контактов (Telegram, Max), затем «Опубликовать».
- Хранилища: база Upstash Redis и Vercel Blob общие с проектом `psixolog`, данные Ивана лежат отдельно (ключи `ugrin:*`, фото в `ugrin/media/`). При желании подключите отдельную базу в Vercel → Storage и замените `KV_REST_API_*` и `BLOB_READ_WRITE_TOKEN`.
- Обновить сайт: `vercel deploy --prod` из этой папки.

## GitHub

- Код: https://github.com/MisterHarryX/ivan-ugrin (открытый). Пароли, заявки и данные (`.env.local`, `.data/`) в репозиторий не попадают.
- Копия на GitHub Pages: https://misterharryx.github.io/ivan-ugrin/ — та же страница. Заявки, свободное время и правки из редактора она берёт с сервера на Vercel (в `server/http.ts` этот адрес разрешён), поэтому заявки с обеих копий попадают в один кабинет. Сам кабинет и редактор работают только на Vercel.
- Обновить копию на GitHub Pages: `npm run deploy:pages` (собирает в `dist-pages` и отправляет в ветку `gh-pages`).
- Чтобы Vercel сам пересобирал сайт после каждого `git push`, в GitHub нужно один раз установить приложение Vercel (https://github.com/apps/vercel) и подключить репозиторий: `vercel git connect`.

## Блоки страницы

1. Первый экран. В шапке крупно «Иван Угрин · Интегральный психолог». Вторая строка заголовка сменяется («Она — за вас.» → «Она обучает вас.» → «Всё происходит во благо.»): длинная фраза уменьшается под ширину колонки. Под кнопками три формата без цен: онлайн, очно (м. Таганская), пакеты — каждый ведёт к ценам. Живописный портрет в круге (лицо целиком, чуть плеч) оживает: шевелится листва, бликует река. Под портретом, как на Таплинке: более 10 лет практики, более 1000 часов консультаций, более 100 благодарных клиентов (числа досчитываются). На телефоне портрет стоит первым.
2. Бегущая строка: «Возможно всё», «Путь начинается с первого шага», «Ты хозяин своего счастья».
3. С чем можно прийти: 6 запросов из анкеты B17.
4. О себе: фото «намасте», образование и регалии, кредо «Свобода, Сила, Счастье». Затем «Принципы моей работы»: пять раскрывающихся панелей с рисунками, текст Ивана без правок.
5. **Метод «Преображение»**. Над заголовком «Авторский метод», крупно «Преображение», под ним «Современная методика на основе вечной мудрости». Витальный круг из пяти точек (сознание, чувства, мысли, желания, действия), в любую можно нажать. Пять этапов (Принятие → Поступок): с каждым этапом символ дорисовывается золотом и на пятом собирается целиком. Ниже опорные методы.
6. Как начинается работа, затем форматы и цены: онлайн — консультация 6 000 ₽ / терапевтический сеанс 9 000 ₽; очно (м. Таганская) — 7 000 ₽ / 10 000 ₽; пакет из 10 встреч с экономией 15% (консультации 49 000 ₽ онлайн / 68 000 ₽ очно, терапия 76 000 ₽ / 84 000 ₽). Отдельно группа «Мастер Жизни». Те же пять вариантов — в форме записи.
7. Кадр из подкаста.
8. Отзывы с B17: колода карточек (свайп, стрелки, клавиатура), фильтр по темам, подсветка ключевой фразы, полный текст авторов.
9. «А что сейчас с вами?» и дыхательная пауза.
10. Где проходят встречи: две карточки с рисунками (высотка у Таганской, видеозвонок) и цветными точками линий метро; своя рисованная схема центра — камера наезжает на станцию; «Онлайн» — глобус со связями.
11. Вопросы, затем запись: форма, Telegram, Max или звонок, профиль на B17.
12. Отдельно проект «Протри Внутри»: Telegram, Дзен, YouTube и плеер выпусков. Видео загружается только по нажатию.

«Возможно всё» — буквы поднимаются по очереди, по надписи бежит золотой блик, буквы у курсора загораются (`src/components/layout/FooterWord.tsx`). Ниже — быстрые ссылки на связь и цитата Ивана с B17 («Нет таких ситуаций, из которых бы не было выхода…»), текст в `site.ts` → `footer`.

## Телефоны, планшеты, большие экраны

- Проверено без горизонтальной прокрутки на ширинах 320, 360, 390, 430, 768, 1024, 1366, 1920, 2560 и в альбомной ориентации телефона (844×390).
- iOS/Android: цвет строки состояния (`theme-color`), иконки для «На экран Домой» (`apple-touch-icon.png`, `icon-192/512.png`, `site.webmanifest`), без синей подсветки при нажатии, без выделения текста кнопок долгим нажатием, поля ввода 16px (iPhone не приближает страницу), отступы от «чёлки» в альбомной ориентации.
- Сборка добавляет префиксы для старых Safari (iOS 15–17) через lightningcss — настройки в `vite.config.ts`.
- На очень больших мониторах (от 2200px) колонка шире и шрифт чуть крупнее.
